# navika.io

My personal website.

## Tech Stack

- Static HTML/CSS and optional JS hosted on GitHub Pages
- Custom domain: [navika.io](https://navika.io)
- No SSG (for now), no build process

## Local Development

```shell
# Serve locally (any simple HTTP server works)
python -m http.server
# or
npx serve -p 8000
```

Open http://localhost:8000
